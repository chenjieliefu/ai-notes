## 推荐阅读顺序

1. 先阅读《AI 入门》，建立训练、推理、大语言模型和 AI 应用的整体框架。
2. 再阅读《Tokenization》，理解文本如何被切分为模型能够处理的离散单元。
3. 接着阅读《Embedding》，理解 token 如何映射为语义向量，以及向量检索的数学基础。
4. 阅读《注意力机制》，理解 Transformer 如何组合上下文信息。
5. 阅读《提示工程》，学习如何清晰组织任务、证据、约束与输出协议。
6. 然后阅读《RAG》，理解如何让模型基于外部可信资料回答问题。
7. 阅读《AI 评估》，学习如何用离线、在线和安全指标验证系统是否真正可靠。
8. 接着阅读《AI Agent》，理解大模型如何调用工具，并在权限与控制边界内完成多步任务。
9. 阅读《微调》，理解何时通过训练让模型适应稳定任务，以及如何控制数据与安全风险。
10. 阅读《知识蒸馏》，理解如何把教师模型的任务能力迁移给更小的学生模型。
11. 最后阅读《模型量化》，理解如何在质量门槛内降低显存、延迟和部署成本。
12. 后续笔记将围绕模型原理、应用工程、评估体系和安全治理逐步展开。
