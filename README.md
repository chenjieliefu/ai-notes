## 推荐阅读顺序

1. 先阅读《AI 入门》，建立训练、推理、大语言模型和 AI 应用的整体框架。
2. 再阅读《Tokenization》，理解文本如何被切分为模型能够处理的离散单元。
3. 接着阅读《Embedding》，理解 token 如何映射为语义向量，以及向量检索的数学基础。
4. 阅读《注意力机制》，理解 Transformer 如何组合上下文信息。
5. 阅读《采样策略》，理解模型如何从概率分布中选择下一个 Token，以及怎样平衡稳定性与多样性。
6. 阅读《多模态模型》，理解图片如何变成视觉 token，并与语言表示对齐和融合。
7. 阅读《KV Cache》，理解自回归生成如何复用注意力中间结果，以及长上下文的显存代价。
8. 阅读《投机解码》，理解草稿模型与目标模型怎样通过多 token 验证减少串行生成轮次。
9. 阅读《混合专家模型》，理解稀疏路由如何扩大模型容量，以及它带来的系统成本。
10. 阅读《提示工程》，学习如何清晰组织任务、证据、约束与输出协议。
11. 阅读《结构化输出》，理解如何用模式约束、应用校验和失败恢复把模型结果接入程序。
12. 然后阅读《RAG》，理解如何让模型基于外部可信资料回答问题。
13. 阅读《AI 幻觉》，理解流畅回答为何仍会失真，以及如何用证据与产品机制治理。
14. 阅读《AI 评估》，学习如何用离线、在线和安全指标验证系统是否真正可靠。
15. 阅读《模型路由》，理解如何依据任务、风险、延迟和成本选择模型及回退路径。
16. 接着阅读《AI Agent》，理解大模型如何调用工具，并在权限与控制边界内完成多步任务。
17. 阅读《AI 记忆系统》，理解 Agent 如何保存、检索、更新和遗忘跨会话信息。
18. 阅读《上下文压缩》，理解如何在有限 token 中保留任务状态、证据与关键历史。
19. 阅读《提示注入》，理解外部网页、文档和工具结果如何影响 Agent，以及怎样建立系统级防线。
20. 阅读《合成数据》，理解如何生成、验证和筛选训练及评估样本，并避免污染与分布偏差。
21. 阅读《微调》，理解何时通过训练让模型适应稳定任务，以及如何控制数据与安全风险。
22. 阅读《偏好对齐》，理解 RLHF 与 DPO 如何利用比较数据塑造模型行为，以及对齐中的常见偏差。
23. 阅读《知识蒸馏》，理解如何把教师模型的任务能力迁移给更小的学生模型。
24. 最后阅读《模型量化》，理解如何在质量门槛内降低显存、延迟和部署成本。
25. 后续笔记将围绕模型原理、应用工程、评估体系和安全治理逐步展开。
