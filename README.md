## 推荐阅读顺序

1. 先阅读《AI 入门》，建立训练、推理、大语言模型和 AI 应用的整体框架。
2. 再阅读《Embedding》，理解语义表示与检索的数学基础。
3. 接着阅读《注意力机制》，理解 Transformer 如何组合上下文信息。
4. 然后阅读《RAG》，理解如何让模型基于外部可信资料回答问题。
5. 最后阅读《AI 评估》，学习如何用离线、在线和安全指标验证系统是否真正可靠。
6. 后续笔记将围绕模型原理、应用工程、评估体系和安全治理逐步展开。
